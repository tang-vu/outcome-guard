# Evidence limitations

- `market-snapshot.json` is a genuine Shannon read. The main composer screenshot uses a deterministic fixture for demo reliability.
- The latest live market passed market and plan checks but failed closed because signer-dependent premium risk, gas balance, and authorization were unknown.
- `execution-receipt.json` and `settlement-receipt.json` are blocker records, not claims of completed lifecycle stages.
- No private key, wallet signature, transaction hash, fill, reconciled position, redemption, deployment URL, or video is present.
- The working-tree scanner is not a substitute for the required full-history scan immediately before public release.
- Binary Event Contracts create nonlinear basis risk and do not perfectly hedge spot exposure.
